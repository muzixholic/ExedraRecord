# ExedraRecord 현재 상태

갱신일: 2026-10-29

## 서버 자료로 로컬 갱신

맥·윈도 입력툴 1.7.0에 서버 공개 자료 다운로드와 로컬 전체 갱신을 추가했다. 기억·포트레이트 화면에서 실행할 수 있다. 사용자 확인 전에는 원본을 바꾸지 않으며 적용 전 자동 백업, 로컬 변경 감지, 일반 오류 시 복원을 수행한다. 서버에 실제 반영하거나 현재 사용자의 로컬 자료를 교체하는 시험은 수행하지 않았다.

관련 결정: [서버 자료 로컬 갱신 ADR](adr/0001-서버-자료-로컬-갱신.md).

## 검증

- 신규 갱신 테스트 17개 통과. 기존 연결·윈도 저장소 테스트를 포함한 관련 테스트 44개 통과.
- 전체 테스트 162개 중 160개 통과. 기존 입력 자료인 히이라기 네무 「창조의 아이들」과 알리나 그레이 「메리골드 다다이즘」의 원문·번역 수치 표기 비교 2건은 이전과 동일하게 실패한다. 사용자 입력 자료는 수정하지 않았다.
- 맥 arm64 앱 빌드와 윈도 x64 ZIP 1.7.0 빌드 성공. ZIP 무결성과 신규 서비스·양쪽 화면·스타일 파일 포함, 맥 앱의 공통 소스 일치를 확인했다.
- 실제 서버의 기억 54개·포트레이트 3개 상세 형식을 확인했다. 전체 이미지 165개 다운로드 시험은 시험용 총 180초 제한으로 53개 다운로드 후 중단했다. 앱 자체에는 이 전체 시간 제한을 적용하지 않았다.
- 실제 서버 기억·포트레이트 각 1건과 이미지 4개로 임시 폴더에 다운로드·적용·백업까지 성공했다. 실제 프로젝트 자료와 서버는 변경하지 않았다.
- 윈도 실기기에서 이번 갱신 버튼을 누르는 검증과 전체 이미지 다운로드 완료 확인은 남아 있다. 강제 종료 시 자동 복원은 보장하지 않으며 수동 복원 절차를 사용 안내에 기록했다.
- 빌드 파일: `dist/기억 입력 도구.app`, `dist/windows/ExedraRecordEditor-Windows-1.7.0-x64.zip`.

## 파일 정리와 공개 준비

- 2026-10-29 사용자 요청으로 미커밋 서버 자료 로컬 갱신 기능, 기억 25건과 연결 이미지·캐릭터 공통 정보를 함께 커밋·푸시한다. 이 요청은 이번 작업에 대한 승인이고 이후 자동 커밋·푸시 권한으로 확장하지 않는다.
- 기억 54건·포트레이트 3건의 편집 형식과 연결 이미지 165개를 확인했다. 모든 이미지에 참조가 있어 원본을 삭제하지 않았다.
- 오래된 성공 배포 작업 사본 6개, 윈도 1.5.1·1.6.0 ZIP, 재생성 가능한 윈도 중간 빌드·메타데이터를 정리했다. 최초 정리에서 약 1.53GB를 확보했다. 최신 1.7.0·직전 1.6.1 ZIP, 맥 앱, 최신 성공 배포 사본, 미완료 작업 사본과 사용자 백업은 보존한다.
- README를 현 기능·양방향 자료 흐름·윈도 실행 확인 범위·검증 제한에 맞춰 재구성했다. 윈도 사용 안내와 후속 작업 문서도 갱신했다.
- 이번 재검증에서 전체 Node.js 테스트는 이전과 같은 160/162 통과이며, 2건의 기존 번역 수치 비교 실패는 유지된다. 맥 Swift 저장소 검증은 통과했다. 비밀 키 패턴·Git 파일 크기·README 상대 링크·JSON 및 이미지 참조 검사도 통과했다.
- 최신 윈도 ZIP에는 수정된 사용 안내를 다시 포함한다. 구체적인 푸시 결과는 Git 이력과 원격 main으로 확인한다.

## 지식 저장소 및 작업 정책

ExedraRecord Basic Memory 프로젝트는 아직 등록·지정되지 않았다. 저장소의 프로젝트 문서로 현황을 남기며 다른 프로젝트 KB에는 저장하지 않는다. 최신 사용자 지침에 따라 자동 커밋·푸시는 하지 않는다. 저장소 AGENTS.md의 이전 자동 커밋 규칙보다 최신 사용자 지침이 우선한다.
