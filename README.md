# 엑세드라 레코드

**마법소녀 마도카☆마기카 Magia Exedra**의 비공식 한국어 데이터베이스입니다. 공식 일본어 원문과 한국어 번역을 함께 기록하며, 게임의 キオク는 **기억**으로 표기합니다.

[공개 사이트](https://exedra-record.chm1610.workers.dev) · [입력툴 사용 안내](editor/사용안내.md) · [윈도판 사용 안내](editor/windows/사용안내.md) · [현재 작업 상태](docs/current-state.md)

## 구현된 기능

### 기억 도감

- 목록·상세 화면, 일러스트 썸네일, 한국어·일본어 이름 검색과 페이지 이동
- 속성·역할·희귀도·입수 구분·작품·마기아 레코드 소속 그룹 필터
- 능력치·스킬 변형·고유 효과·한계돌파 1~5단계의 일본어 원문과 한국어 번역
- 기억 일러스트와 유튜브 주소를 이용한 PV 삽입
- 성우·위키 문서 링크와 같은 캐릭터 그룹의 다른 기억 자동 표시

속성은 불·물·나무·빛·어둠·무, 역할은 어태커·브레이커·힐러·버퍼·디버퍼·디팬더, 희귀도는 5성·4성·3성 순입니다. 속성·역할·작품은 여러 개 선택할 수 있습니다. 같은 필터의 여러 값은 **OR**, 서로 다른 필터는 **AND**로 적용하며 필터와 페이지 상태는 주소에 보존됩니다.

기억마다 작품 하나를 지정하고, 마기아 레코드는 소속 그룹을 여러 개 지정할 수 있습니다. 작품 필터에서 다른 작품도 함께 선택하면 하위 그룹 조건은 마기아 레코드에만 적용합니다. 작품은 마도카☆마기카, 마기아 레코드, 오리코☆마기카, 타루토☆마기카, 스즈네☆마기카, 소라나☆마기카, 콜라보를 지원합니다.

입수 구분은 한정·통상·배포입니다. 아쿠아 템페스트 소라나는 배포로 기록하며, 별도 배포 정보 없이 공식 소개에 한정 표시가 없는 기억은 통상으로 분류합니다.

### 포트레이트 도감

이미지, 5성·4성 등급, 이름, **최대 한계돌파** HP·공격력·방어력, 강화 +0~+5의 어빌리티를 기록합니다. 이름 끝의 강화 표기는 저장할 때 제외합니다. 각 강화 단계에 여러 효과와 조건을 입력할 수 있으며 확인하지 못한 단계나 낮은 한계돌파 수치는 추정하지 않습니다.

효과 필터는 어빌리티 설명의 공격력·스피드 등을 자동 분류하고, 수동으로 지정한 태그도 사용합니다. 여러 효과 태그는 OR로 검색합니다. 특정 강화 단계 또는 모든 단계에서 찾으며, 이름·스테이터스·조건만으로 효과가 일치한다고 판단하지 않습니다.

입수처는 배포·스토리·푸엘라 픽투러 중 하나입니다. 스토리 참조 필드는 준비되어 있으나 스토리 도감 구현 전에는 목록 선택을 비활성화합니다.

### 수정 요청과 캐릭터 그룹

기억·포트레이트 상세 화면 최하단의 **수정 요청**으로 내용을 접수합니다. 입력툴의 **수정 요청 관리**에서 일시(한국 시간), 페이지, 요청사항, 처리 여부를 확인하고 완료 처리할 수 있습니다. 상태 필터와 100건 단위 페이지 이동을 지원합니다. 완료 버튼은 요청 상태만 바꾸므로 실제 도감 수정은 별도로 저장·서버 반영해야 합니다.

악마 호무라는 아케미 호무라, 얼티밋 마도카는 카나메 마도카의 바리에이션으로 묶습니다. 표시 이름은 유지하고 **캐릭터 그룹**을 따로 지정하며, 이후 다른 바리에이션도 같은 방식으로 연결할 수 있습니다.

성우와 문서 주소는 그룹 공통값을 사용합니다. **이 기억만 성우 개별 지정**을 선택하면 해당 기억만 다른 값을 저장합니다. 수동 성우 가져오기 버튼은 같은 그룹의 기존 이름·주소를 함께 복사합니다. 문서 주소는 나무위키 → 한국어 위키백과 → 일본어 위키백과 순으로 확인해 직접 입력하며, 주소가 없으면 이름만 표시합니다.

## 입력툴과 자료 관리

입력툴은 별도 웹 서버를 실행하지 않는 맥·윈도 스탠드얼론 앱입니다. 프로젝트 폴더를 선택해 JSON과 이미지를 직접 편집합니다. 새 기억·포트레이트 입력, 수정, 이미지 가져오기, 일러스트 썸네일 생성, 로컬 저장은 오프라인으로 동작합니다. 기존 파일 자동 백업과 외부 편집 충돌 감지를 지원합니다.

**앱과 프로젝트 자료는 별도**입니다. 다른 컴퓨터에서 사용하려면 앱과 함께 이 저장소도 내려받아야 합니다. 두 컴퓨터의 자료는 자동으로 동기화되지 않으므로 Git 또는 아래 갱신 기능으로 맞춥니다.

| 기능 | 동작 | 필요한 환경 |
| --- | --- | --- |
| 이미지 초벌 번역·입력 | 기억 소개 이미지 또는 포트레이트 캡처를 전사·번역하고 검토 후 편집기에 적용 | Node.js, 인터넷, ChatGPT 계정으로 로그인한 Codex CLI |
| 서버에 반영 | 저장된 기억·포트레이트·이미지 사본을 준비하고 확인 후 Workers·D1에 반영, 공개 API로 비교 검증 | Node.js, 인터넷, 프로젝트의 Wrangler와 기존 Cloudflare 계정 로그인 |
| 서버 자료로 로컬 갱신 | 서버 공개 자료와 연결 이미지를 내려받아 변경 수 확인 후 백업·교체 | Node.js, 인터넷 |
| 수정 요청 관리 | 요청 조회와 완료 처리 | Node.js, 인터넷, Wrangler와 기존 Cloudflare 계정 로그인 |
| 배포 파일만 만들기 | SQL 마이그레이션 파일 생성 | 오프라인 가능 |

### 이미지 초벌 번역

이미지를 OpenAI로 전송하며 Codex 사용량을 사용합니다. API 키 로그인은 초벌 번역에 사용하지 않습니다. 기억은 원문·번역·스킬·한계돌파를, 포트레이트는 화면에 보이는 강화 단계의 효과와 조건을 추출합니다. 모르는 수치는 비워 두고 검토 사항으로 남깁니다. 결과를 검토해 적용한 뒤 별도로 저장해야 합니다.

기존 일러스트·PV·작품 소속·캐릭터 그룹·성우 개별 지정은 초벌 번역으로 덮어쓰지 않습니다. 포트레이트의 다른 강화 단계와 입수처·스토리 연결도 유지합니다.

### 서버에 반영

저장된 로컬 자료를 고정된 사본으로 준비합니다. 사용자가 확인하면 사이트·이미지 업로드, DB 반영, 공개 상세 자료 비교를 순서대로 진행합니다. 기존 서버 기록은 추가·수정하며 **로컬에 없는 서버 기록을 자동 삭제하지 않습니다**.

### 서버 자료로 로컬 갱신

기억 화면의 **연결 · 기타 도구**, 포트레이트 화면의 왼쪽 하단에서 실행합니다.

1. 편집 중인 내용을 저장합니다.
2. 서버의 공개 기억 상세·포트레이트·캐릭터 공통 정보·연결 이미지를 내려받아 검증합니다. 아직 로컬 원본은 바꾸지 않습니다.
3. 추가·교체·삭제될 파일 수를 확인합니다.
4. **백업 후 로컬 전체 갱신**을 누르면 기존 자료를 백업하고 교체한 뒤 목록을 다시 불러옵니다.

**로컬에만 있는 기억·포트레이트도 백업 후 제거됩니다.** 사용하지 않는 이미지는 유지하며, 서버 비공개 자료·수정 요청·다른 도감·앱 코드·로그인 설정은 갱신 대상이 아닙니다. Codex·Cloudflare 로그인이나 Codex 사용량은 필요하지 않습니다.

준비 이후 로컬 자료가 바뀌면 갱신을 차단합니다. 일반 쓰기 오류는 기존 파일을 복원하지만 강제 종료·전원 차단 시 자동 복원은 보장하지 않습니다. 교체 중에는 앱을 종료하지 마세요. 수동 복원은 [사용 안내](editor/사용안내.md)의 절차를 따릅니다.

## 개발 환경과 실행

| 영역 | 구성 |
| --- | --- |
| 웹 화면 | HTML, CSS, JavaScript |
| 서버·이미지 | Cloudflare Workers와 정적 자산 |
| 데이터베이스 | Cloudflare D1 |
| 맥 입력툴 | Swift, AppKit, WKWebView · Apple Silicon, macOS 13 이상 |
| 윈도 입력툴 | Electron · Windows 10/11 x64 |
| 온라인 도구 | 외부 Node.js, Codex CLI, Wrangler |
| 자동 테스트 | Node.js 기본 테스트 도구, Swift 저장소 검증 |

R2는 아직 연결하지 않았습니다. Node.js 의존성은 잠금 파일에 따라 설치합니다. 현재 웹·온라인 도구의 Wrangler는 Node.js 22 이상, 윈도 앱 소스 빌드 의존성은 22.12 이상을 요구합니다. 기본 편집용 완성 앱 실행에는 별도 Node.js가 필요하지 않습니다.

### 웹 로컬 실행

프로젝트 루트에서 실행합니다.

```sh
npm ci
npm run db:local
npm run dev
```

Wrangler가 출력하는 주소로 접속합니다. 로컬 마이그레이션은 초기 자료를 구성하며 최신 편집 JSON을 자동으로 DB에 반영하지 않습니다.

### 맥 입력툴 빌드

Apple Silicon 맥과 Xcode Command Line Tools가 필요합니다.

```sh
./editor/build.sh
open "dist/기억 입력 도구.app"
```

### 윈도 입력툴 빌드와 실행

```sh
cd editor/windows
npm ci
npm run build:win
```

현재 버전은 **1.7.0**입니다. 빌드 결과인 `ExedraRecordEditor-Windows-1.7.0-x64.zip`은 `dist/windows/`에 생성됩니다. **폴더 전체를 압축 해제**하고 `ExedraRecordEditor.exe`를 실행합니다. exe만 옮기면 실행되지 않습니다. 앱 빌드 결과물은 Git에 포함하지 않습니다.

윈도판은 사용자 PC에서 앱 실행과 Codex·Cloudflare 연결 확인을 검증했습니다. 새 1.7.0의 로컬 갱신 기능을 포함한 윈도 실기기 검증은 추가로 필요합니다. 연결 확인은 실제 Node.js·Codex·Wrangler 경로와 실패 원인을 표시하고, 일반 PATH 외에 fnm 설치 경로도 탐색합니다. 자세한 설치·로그인 안내는 [윈도판 사용 안내](editor/windows/사용안내.md)를 참고하세요.

### 테스트와 확인된 제한

```sh
npm test
```

맥 저장소 검증은 다음으로 실행합니다.

```sh
xcrun swiftc editor/Core.swift editor/Portraits.swift editor/CoreTests.swift -o /tmp/exedra-core-tests
/tmp/exedra-core-tests
```

2026-10-29 기준 전체 Node.js 테스트 162개 중 160개가 통과합니다. 히이라기 네무 「창조의 아이들」과 알리나 그레이 「메리골드 다다이즘」의 원문·번역 수치 표기 비교 2건은 검토가 남아 있습니다. 수치 대조 검사는 원본 이미지 판독이나 번역 의미의 정확성을 보장하지 않습니다. 관련 결과와 실제 서버 다운로드 검증 범위는 [현재 상태](docs/current-state.md)에 기록합니다.

## 자료 구조

| 위치 | 내용 |
| --- | --- |
| `public/` | 웹 화면·작품 정의·캐릭터 공통 정보·공개 이미지 |
| `data/memories/` | 기억별 편집 JSON |
| `data/portraits/` | 포트레이트별 편집 JSON |
| `src/` | 공개 조회 API와 수정 요청 접수 |
| `migrations/` | D1 초기 자료와 변경 이력 |
| `editor/` | 맥·윈도 입력툴과 공통 화면·작업 서비스 |
| `test/` | 자동 테스트와 포트레이트 추출 회귀 자료 |
| `번역/`과 초벌 번역 문서 | 일본어 전사·한국어 번역 검토 기록 |
| `docs/` | 현재 상태와 설계 결정 |

기억 JSON은 `id`, 캐릭터명·기억명, `character_group`, `voice_actor_override`, `work`, `groups`, `stats`, `skills`, `limit_breaks`, 출처·이미지·PV를 기록합니다. 구버전 `group` 필드도 읽으며 새 저장에는 `groups` 배열을 사용합니다.

포트레이트는 `stats_max`, +0~+5의 `ability_levels`, 각 단계의 `effects`를 기록합니다. 효과마다 한국어·일본어 설명·조건·태그를 따로 저장합니다. `acquisition_type`은 `distribution`·`story`·`puella-pictura` 중 하나이고 `story_id`는 향후 스토리 도감의 식별자를 연결합니다. 추정한 수치나 존재하지 않는 스토리 참조를 만들지 않습니다.

## API와 Cloudflare 배포

| 요청 | 동작 |
| --- | --- |
| `GET /api/memories` | 공개 기억 목록 요약 |
| `GET /api/memories/<id>` | 공개 기억 전체 상세 |
| `GET /api/portraits` | 공개 포트레이트와 강화 단계별 효과 |
| `GET /api/portraits/<id>` | 공개 포트레이트 상세 |
| `POST /api/correction-requests` | 수정 요청 접수 |

도감 자료 API는 조회 전용입니다. 공개 수정 요청 API는 접수만 허용하고 조회·완료 처리를 허용하지 않습니다. 요청은 최대 2,000자이며 개인정보를 입력하지 않습니다. 원본 IP는 요청 테이블에 저장하지 않고 일별 해시로 접수량을 제한합니다. 요청 내역은 별도 테이블에 보존되어 도감 자료 반영과 분리됩니다.

웹 경로는 `#memories`, `#memories/<id>`, `#portraits`, `#portraits/<id>`입니다. 성우 공통 정보는 정적 `characters.json`을 함께 읽습니다.

**이 저장소의 Cloudflare 설정은 기존 운영 계정과 DB를 가리킵니다.** 기존 운영자는 DB를 새로 만들지 않습니다.

```sh
npx wrangler login
npm run db:remote
npm run deploy
```

`db:remote`는 미적용 마이그레이션을 실행하고 `deploy`는 웹 화면·API·정적 자산을 배포합니다. 편집 JSON까지 일괄 반영하려면 입력툴의 **서버에 반영**을 사용합니다. 수정 요청 테이블도 마이그레이션 또는 입력툴의 서버 반영 과정에서 준비합니다.

다른 계정으로 운영하려면 Wrangler 설정과 입력툴의 고정 운영 대상 검사·조회 주소도 함께 변경해야 합니다. 계정·DB 식별자는 인증 키가 아니며 실제 배포에는 해당 계정 권한이 필요합니다.

## 저장소에서 제외하는 자료

`.gitignore`로 인증·환경 설정(`.env*`, `.dev.vars`), 의존성(`node_modules/`), 로컬 Workers 상태(`.wrangler/`), 빌드(`dist/`), 백업(`data/editor-backups/`), 작업 사본(`.editor-jobs/`), 생성된 윈도 공통 화면·서비스 복사본과 맥 메타데이터를 제외합니다.

백업과 작업 사본에는 로컬 자료가 들어갑니다. 폴더를 직접 압축할 때는 `.gitignore`가 적용되지 않으므로 공개 범위를 별도로 확인해야 합니다. 비밀 키·로그인 파일·개인 로그는 커밋하지 않습니다.
