# 엑세드라 레코드

**마법소녀 마도카☆마기카 Magia Exedra**의 비공식 한국어 데이터베이스입니다. 공식 일본어 원문과 한국어 번역을 함께 보존하고, 오프라인 맥 입력 앱으로 자료를 관리합니다.

[공개 사이트 바로가기](https://exedra-record.chm1610.workers.dev/#memories)

## 현재 기능

- 기억 목록과 개별 상세 페이지, 이름 검색, 24개 단위 페이지 나누기
- 속성·역할·작품·마기아 레코드 그룹 다중 필터
- 희귀도·입수 구분 필터, 이름순·희귀도순 정렬
- 능력치, 스킬·어빌리티, 한계돌파의 일본어 원문과 한국어 번역
- 일러스트·썸네일과 YouTube PV 삽입
- 캐릭터 공통 성우 이름·위키 링크와 동일 캐릭터의 다른 기억 자동 표시
- 네이티브 맥 앱에서 기억 입력·수정, 이미지 가져오기, 자동 백업과 충돌 감지
- 공식 소개 이미지의 AI 초벌 번역과 저장된 자료의 Cloudflare 서버 반영

같은 필터 안의 여러 선택은 **OR**, 서로 다른 필터는 **AND**로 적용합니다. 작품을 여러 개 선택한 경우 하위 그룹 조건은 마기아 레코드에만 적용합니다. 필터·페이지 상태는 주소에 보존됩니다.

입력 자료는 기억마다 작품 하나를 지정하며, 마기아 레코드 소속은 여러 그룹에 동시에 소속될 수 있습니다. 작품에는 마도카☆마기카, 마기아 레코드, 오리코☆마기카, 타루토☆마기카, 스즈네☆마기카, 소라나☆마기카, 콜라보를 제공합니다.

## 기술 구성

| 영역 | 구성 |
| --- | --- |
| 웹 화면 | HTML, CSS, JavaScript |
| 서버 | Cloudflare Workers |
| 데이터베이스 | Cloudflare D1, 기억별 JSON 저장 |
| 이미지 | Workers 정적 자산 |
| 입력 앱 | Swift, AppKit, WKWebView / Apple Silicon·macOS 13 이상 |
| 온라인 도구 | Codex CLI, Wrangler |
| 테스트 | Node.js 기본 테스트 도구, Swift 저장 검증 |

R2는 아직 연결하지 않았습니다. 공개 API는 조회 전용이며 쓰기 요청은 허용하지 않습니다.

## 로컬 실행

Node.js와 npm이 필요합니다.

```sh
npm ci
npm run db:local
npm run dev
```

Wrangler가 출력하는 로컬 주소로 접속합니다. 로컬 마이그레이션은 초기 자료를 구성합니다. 최신 편집 JSON을 자동으로 DB에 동기화하지는 않습니다.

```sh
npm test
```

## 맥 입력 앱 빌드와 사용

Xcode Command Line Tools가 설치된 Apple Silicon 맥에서 실행합니다.

```sh
./editor/build.sh
open "dist/기억 입력 도구.app"
```

앱에서 이 프로젝트 폴더를 선택하고 자료를 편집합니다. 일반 입력·수정·이미지 가져오기는 오프라인으로 동작합니다. 앱 결과물은 저장소에 포함하지 않으며 각 맥에서 빌드합니다.

- **기억 저장**: JSON과 캐릭터 공통 정보를 로컬에 저장합니다. 기존 자료는 자동 백업합니다.
- **이미지로 새 기억 만들기 / 초벌 번역**: 이미지를 OpenAI로 전송하며, 기존 ChatGPT 계정의 Codex 로그인과 사용량을 사용합니다. 결과를 검토해 적용한 뒤 별도로 저장합니다. API 키 로그인은 번역에 사용하지 않습니다.
- **서버에 반영**: 저장된 자료와 이미지를 고정된 사본으로 준비하고, 확인 후 사이트 배포·DB 갱신·공개 조회 검증을 수행합니다. 인터넷 연결과 기존 Cloudflare 로그인이 필요합니다.
- **성우**: 같은 캐릭터의 모든 기억이 이름·문서 주소를 공유합니다. 위키 검색 버튼으로 문서를 찾고 주소를 직접 입력합니다.

자세한 내용은 [입력 도구 사용 안내](editor/사용안내.md)를 참고하세요.

## 자료 구조

```text
public/                 웹 화면과 공개 이미지
  characters.json       캐릭터 공통 성우 정보
  affiliations.js       작품·그룹 정의
  images/               공식 소개 이미지, 일러스트, 썸네일
src/worker.js           조회 API
data/memories/         기억별 편집 JSON
migrations/             D1 초기 자료와 변경 내역
editor/                 맥 입력 앱과 온라인 작업 도구
test/                  자동 테스트
번역/                   일본어 전사와 한국어 초벌 번역 문서
```

JSON의 주요 필드는 다음과 같습니다.

| 필드 | 용도 |
| --- | --- |
| `id` | 기억 고유 식별자 |
| `character_ko`, `character_ja` | 한국어·일본어 캐릭터명 |
| `name_ko`, `name_ja` | 한국어·일본어 기억 이름 |
| `work`, `groups` | 작품 하나와 마기아 레코드 소속 그룹 목록 |
| `stats`, `skills`, `limit_breaks` | 능력치·스킬·한계돌파 |
| `image` | 공식 소개 출처 이미지 |
| `illustration_url`, `thumbnail_url` | 일러스트·목록용 썸네일 |
| `pv_url` | YouTube 영상 주소 |
| `source_url`, `source_note` | 출처와 확인 메모 |

구버전 단일 그룹 필드 `group`도 읽을 수 있으며, 앱에서 새로 저장할 때는 `groups` 배열을 사용합니다. 미확인 수치나 출처는 추정해 채우지 않습니다. 초벌 번역은 검수 중이며, 원문과 번역의 수치 대조 테스트가 원본 이미지 판독의 정확성을 보장하지는 않습니다.

## 공개 API

| 요청 | 반환 |
| --- | --- |
| `GET /api/memories` | 공개 기억 목록용 요약 |
| `GET /api/memories/<id>` | 공개 기억의 전체 상세 JSON |

웹 화면은 `#memories`와 `#memories/<id>` 경로를 사용합니다. 성우 공통 정보는 공개 정적 자료인 `characters.json`을 함께 읽어 표시합니다.

## Cloudflare 배포

**이 저장소의 설정은 현재 운영 계정과 DB를 가리킵니다.** 기존 운영자는 DB를 다시 만들 필요가 없습니다.

```sh
npx wrangler login
npm run db:remote
npm run deploy
```

`db:remote`는 아직 적용하지 않은 마이그레이션을 실행하며, `deploy`는 웹 화면·서버·정적 자산을 배포합니다. 편집 JSON의 최신 내용을 일괄 반영하려면 입력 앱의 **서버에 반영**을 사용하세요. 반영은 기존 기억을 추가·수정하며 자동 삭제하지 않습니다.

다른 계정으로 복제해 운영할 경우 자신의 D1을 만들고 `wrangler.jsonc`를 변경해야 합니다. 입력 앱의 배포 대상 검사도 `editor/service/deployment.mjs`와 `editor/service/runner.mjs`에서 함께 변경해야 합니다. 계정·DB 식별자는 인증 키가 아니며 실제 배포에는 해당 계정 권한이 필요합니다.

## 공개 제외 자료

다음 항목은 `.gitignore`로 제외합니다.

- 로그인·환경 설정: `.env*`, `.dev.vars`
- 의존성·로컬 상태: `node_modules/`, `.wrangler/`
- 앱 빌드: `dist/`
- 자동 백업·배포 작업 사본: `data/editor-backups/`, `.editor-jobs/`
- 맥 메타데이터: `.DS_Store`

인증 키나 로그인 파일을 저장소에 추가하지 마세요. 폴더를 직접 압축해 배포할 때는 `.gitignore`가 적용되지 않습니다.
