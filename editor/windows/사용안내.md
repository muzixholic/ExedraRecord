# 윈도 기억 입력 도구

## 실행 파일

`ExedraRecordEditor-Windows-1.4.0-x64.zip`을 **폴더 전체로 압축 해제**하고 `ExedraRecordEditor.exe`를 실행합니다. exe만 따로 옮기면 실행되지 않습니다. 기본 입력 기능에는 Node.js나 브라우저 설치가 필요하지 않으며 웹 서버도 실행하지 않습니다.

윈도 10/11 64비트 일반 PC용입니다. 이번 버전은 맥에서 윈도용 패키지를 만들고 저장·데이터 처리 테스트를 수행했습니다. **윈도에서 실제 실행, 이미지 처리, 로그인·배포는 아직 검증하지 않았습니다.** ARM 윈도 전용 빌드는 포함하지 않습니다.

코드 서명은 하지 않았으므로 윈도 또는 조직의 보안 정책에 따라 실행 확인이나 제한이 발생할 수 있습니다. 회사 PC에서는 회사의 프로그램 설치·실행 정책을 따르세요.

## 처음 실행할 때

1. [GitHub 프로젝트](https://github.com/muzixholic/ExedraRecord)를 내려받거나 복제합니다. 앱 ZIP과 프로젝트 자료는 별도입니다.
2. 앱에서 `data/memories`, `public/images`, `migrations` 폴더가 들어 있는 **ExedraRecord 프로젝트 루트**를 선택합니다.
3. 기억을 선택해 편집합니다. **Ctrl+S** 또는 **기억 저장**으로 로컬 JSON에 저장합니다.

앱은 마지막으로 선택한 폴더 경로를 윈도 사용자별 앱 설정에 저장합니다. 맥에서 입력하던 기억 JSON·이미지·공통 성우 정보를 그대로 사용할 수 있습니다. 두 컴퓨터의 파일은 자동 동기화되지 않으므로 작업 전후 Git 등으로 최신 자료를 맞추세요.

## 지원 기능

- 기존 기억 수정, 새 기억 입력, 스킬·한계돌파 편집
- 포트레이트 입력·수정, +0~+5 단계별 복수 효과·조건·분류 태그
- 작품 태그 및 마기아 레코드 그룹 중복 선택
- 캐릭터 공통 성우·위키 주소, 위키 검색
- PNG·JPEG 이미지 가져오기, 일러스트와 작은 썸네일 생성
- 유튜브 PV 주소 저장
- 이전 파일 자동 백업과 외부 변경 충돌 감지
- SQL 마이그레이션 내보내기
- Codex 이미지 초벌 번역과 Cloudflare 서버 반영

이미지는 최대 50MB이며 앱으로 가져오면 최대 변 3,000픽셀 PNG와 640픽셀 JPEG 썸네일을 만듭니다. 미리보기·파일 변환은 윈도 실기기에서 확인해 주세요. 원본 파일은 수정하지 않습니다. 상세 사용 흐름은 [공통 사용 안내](../사용안내.md)를 참고하세요. 맥의 ⌘S는 윈도에서 Ctrl+S입니다.

## 초벌 번역·서버 반영을 사용할 때

기본 편집은 오프라인으로 가능합니다. 온라인 기능에는 인터넷과 **해당 윈도 PC의 로그인**이 필요합니다. 맥의 인증 파일을 복사하지 않습니다.

1. Node.js LTS와 npm을 준비합니다.
2. 프로젝트 루트에서 `npm ci`를 실행해 Wrangler를 설치합니다.
3. 초벌 번역을 쓸 경우 Codex CLI를 설치합니다. npm 설치를 사용한다면 `npm install -g @openai/codex`를 실행합니다.
4. 앱의 **연결 · 기타 도구**에서 Codex·Cloudflare 로그인을 진행합니다. 필요하면 터미널에서 `codex login`, `npx wrangler login`으로 먼저 로그인한 뒤 앱을 다시 실행합니다.
5. **연결 확인** 후 초벌 번역 또는 서버 반영을 사용합니다.

초벌 번역은 이미지를 OpenAI로 보내고 Codex 사용량을 소비합니다. ChatGPT 로그인을 사용하며 앱에 별도 API 키를 저장하지 않습니다. 윈도에서는 npm의 `codex.cmd`와 설치된 `codex.exe` 탐색을 지원합니다.

서버 반영 대상은 기존 운영 사이트로 고정되어 있습니다. 실제 자료를 반영할 때만 확인 버튼을 누르세요. 취소해도 이미 완료된 서버 작업은 되돌리지 않습니다.

## 윈도에서 직접 빌드

프로젝트를 받은 뒤 터미널에서 실행합니다.

```powershell
cd editor/windows
npm ci
npm run build:win
```

결과는 프로젝트 루트의 `dist/windows/`에 생깁니다. 개발 실행은 같은 폴더에서 `npm start`를 사용합니다. 패키징에는 인터넷 연결이 필요하지만 만들어진 앱의 기본 입력 기능은 오프라인으로 동작합니다.

## 나중에 확인할 항목

- 한글·공백이 있는 경로에서 앱 실행과 프로젝트 선택
- 기억 저장, 앱 재실행 후 값 유지, 자동 백업 생성
- 작품과 여러 그룹 선택·해제·저장
- 이미지 업로드와 썸네일·미리보기
- 성우 공통 정보가 동일 캐릭터의 다른 기억에도 반영되는지 확인
- 포트레이트 화면 전환, 복수 효과·조건 입력, 강화별 값 유지
- Ctrl+S, 복사·붙여넣기, 미저장 변경 안내
- Codex와 Cloudflare 로그인 및 연결 확인
- 초벌 번역 검토·취소·편집기에 적용
- 승인한 실제 자료에 대한 서버 반영과 취소

포트레이트 화면의 **이미지로 새 포트레이트 만들기** 또는 **인게임 이미지로 초벌 입력**으로 현재 표시된 강화 단계의 정보를 추출합니다. 원문·수치·조건을 검토한 뒤 편집기에 적용하고 입수처를 선택해 저장합니다. 다른 강화 단계와 기존 일러스트·입수처·스토리 연결은 유지합니다. 윈도에서는 실제 로그인·추출·화면 동작의 실기기 검증이 필요합니다.
