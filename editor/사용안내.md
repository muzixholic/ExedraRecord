# 기억 입력 도구

윈도판의 실행·설치 준비는 [윈도판 안내](windows/사용안내.md)를 참고하세요. 아래 ⌘S는 윈도에서 Ctrl+S로 사용합니다.

`dist/기억 입력 도구.app`을 더블 클릭해 실행합니다. 현재 맥(Apple Silicon)에서 실행하는 독립 앱입니다. 입력·수정·이미지 가져오기는 오프라인으로 동작하며 별도 웹 서버가 필요하지 않습니다. 초벌 번역과 서버 반영에는 인터넷 연결이 필요하고, 이 맥의 Node.js·Codex CLI·프로젝트 Wrangler를 사용합니다. Xcode는 다시 빌드할 때만 필요합니다.

## 입력과 수정

1. 앱이 ExedraRecord 프로젝트를 불러옵니다. 다른 위치로 옮겼다면 **프로젝트 폴더 선택**을 누릅니다.
2. 왼쪽 목록에서 기존 기억을 선택하거나 **새 기억**을 누릅니다.
3. 기본 정보(성우 포함), 일러스트·PV, 스킬·어빌리티, 한계돌파, 출처·검토 탭에서 입력합니다. 성우는 선택 사항이며 이미지에서 추정하지 않습니다.
4. **기억 저장** 또는 **⌘S**로 저장합니다. 캐릭터명·기억 이름·능력치는 필수입니다. 확인되지 않은 수치는 추정해 넣지 않습니다.

식별자는 새 기억을 처음 저장할 때 지정합니다. 영문 소문자, 숫자, 하이픈을 사용하며 저장 후에는 변경할 수 없습니다. 기존 자료를 선택해 수정하면 이전 JSON은 `data/editor-backups/식별자/`에 자동 백업됩니다. 다른 프로그램에서 파일을 변경한 경우 충돌을 감지해 덮어쓰기를 막습니다. 여러 앱에서 동시에 같은 자료를 편집하지 마세요.

## 일러스트와 소개 이미지

**일러스트 파일 가져오기**를 누르면 프로젝트의 `public/images/`로 복사합니다. 최대 변 3,000픽셀의 PNG와 최대 변 640픽셀의 JPEG 썸네일을 만들며 사용자가 제공한 원본 파일은 변경하지 않습니다. 가져온 후 **기억 저장**을 눌러야 해당 기억에 연결됩니다. 연결 해제는 파일 자체를 삭제하지 않습니다. 공식 스킬 소개 이미지는 출처·검토 탭에서 따로 가져옵니다.

이미지 파일을 가져온 뒤 저장하지 않고 나가면 복사한 파일은 남아 있습니다. 로컬 파일은 오프라인으로 미리 볼 수 있고, 외부 HTTPS 이미지 주소는 주소만 보관합니다.

PV에는 유튜브 주소를 붙여 넣습니다. 실제 영상은 공개 사이트에서 자동 삽입되며, 오프라인 앱에서는 재생하지 않습니다.

## 이미지에서 초벌 번역

1. 새 기억은 왼쪽 **이미지로 새 기억 만들기**를 눌러 공식 소개 이미지를 선택합니다.
2. 기존 기억은 **출처·검토** 탭의 **이 소개 이미지로 초벌 번역**을 누릅니다. 등록된 소개 이미지가 없으면 파일을 선택합니다.
3. 이 맥에 로그인된 Codex를 통해 이미지를 OpenAI로 보내 원문과 한국어 초벌 번역을 만듭니다. Codex 사용량이 소모됩니다. 별도 API 키를 앱에 저장하지 않습니다.
4. 결과 검토 창에서 원문·번역·능력치·검토 사항을 확인한 뒤 **편집기에 적용**을 누릅니다. 적용하지 않고 닫으면 기존 편집 내용이 유지됩니다.
5. 판독이 불명확한 수치는 빈칸으로 남습니다. 직접 확인하고 **기억 저장**을 눌러 저장합니다. 번역은 자동 저장하거나 자동 공개하지 않습니다.

최초 로그인이 필요하면 **Codex 로그인**을 눌러 브라우저에서 로그인합니다. **연결 확인**에서 Codex·Cloudflare 연결 상태를 볼 수 있습니다. 초벌 번역은 10분 안에 응답하지 않으면 중단되며 다시 시도할 수 있습니다.

## 서버에 반영

1. 편집 중인 기억을 먼저 저장합니다.
2. **서버에 반영**을 누르면 저장된 전체 기억과 이미지의 고정 사본을 만듭니다.
3. 대상 사이트와 기억 개수를 확인한 뒤 **확인한 자료 반영**을 누릅니다.
4. 앱이 기존 Cloudflare 계정으로 사이트·이미지를 배포하고 D1 데이터를 갱신한 뒤, 공개 API를 다시 조회해 저장된 JSON과 비교합니다.

대상은 기존 `exedra-record.chm1610.workers.dev`와 연결된 D1 DB로 고정되어 있습니다. 현재 버전은 삭제를 전파하지 않고 저장된 기억을 추가·수정합니다. 검토 후 편집한 내용은 다음 반영에 포함됩니다. 배포용 사본과 성공 기록은 프로젝트의 `.editor-jobs/`에 남습니다.

오류가 나면 완료 단계를 안내합니다. 이미지 배포와 DB 반영은 하나의 원자적 작업이 아니므로 일부만 반영될 수 있습니다. 같은 자료로 다시 반영할 수 있습니다. **작업 취소**는 실행 중인 작업을 중단하지만 이미 서버에 반영된 내용까지 되돌리지는 않습니다. 실행 중에는 편집·폴더 전환·앱 종료가 제한됩니다.

Cloudflare 로그인이 만료되면 **Cloudflare 로그인**을 누릅니다. 인증 정보는 기존 Codex·Wrangler가 관리하며 앱은 비밀 키를 저장하지 않습니다.

**배포 파일만 만들기**는 수동 반영용 SQL을 만드는 기존 기능입니다. 앱의 **서버에 반영**에서는 별도 SQL 내보내기를 하지 않아도 됩니다.

## 후순위 작업

- 불완전한 입력을 별도 임시 보관하는 초안 기능.
- 여러 이미지의 일괄 초벌 번역과 번역 용어집 관리.

## 다시 빌드

개발 환경에서 `editor/build.sh`를 실행합니다. 별도 외부 패키지를 설치하지 않고 macOS 기본 AppKit·WebKit으로 빌드합니다.

## 캐릭터 공통 성우 정보

기본 정보의 성우 이름과 문서 주소는 같은 캐릭터의 모든 기억에서 공유합니다. 일본어 이름이 둘 다 있으면 일본어 이름을, 없으면 한국어 이름을 비교합니다. 공백·전각 차이는 무시하며 다른 이름으로 등록된 캐릭터는 따로 취급합니다. 이름을 수정해 기존 캐릭터와 연결할 때는 성우 값을 확인해 주세요.

성우 문서 주소는 나무위키 → 한국어 위키백과 → 일본어 위키백과 순으로 찾아 직접 입력합니다. 검색 버튼은 기본 브라우저에서 검색 결과를 열며 자동으로 문서 존재 여부를 판정하지 않습니다. 주소가 없으면 사이트에는 이름만 표시합니다.

공통 정보는 프로젝트의 `public/characters.json`에 저장하고 변경 전 백업을 남깁니다. 앱의 서버 반영으로 사이트에 업로드됩니다. 기존 기억 JSON의 성우 정보는 공통 정보가 등록되기 전까지 그대로 표시합니다.

## 작품과 마기아 레코드 그룹

작품은 기억마다 하나씩 지정합니다. 마기아 레코드는 하위 그룹을 태그 버튼으로 하나 이상 선택합니다. 여러 그룹에 중복 소속될 수 있습니다. 다른 작품으로 변경하면 그룹 선택을 지웁니다. 기존 단일 그룹은 자동으로 하나의 태그로 읽습니다. 목록에서 여러 그룹을 선택하면 하나라도 일치하는 기억을 표시합니다. 기존 미등록 자료는 그대로 저장할 수 있습니다. 작품·그룹은 성우 공통 정보와 달리 기억별 정보입니다. 사이트 목록의 작품·그룹 필터와 상세 정보에 표시하며 서버 반영 버튼으로 게시합니다. 그룹 한글 표기는 첨부된 게임 화면의 일본어 명칭을 옮겼습니다.

## 포트레이트 편집

상단의 **포트레이트 편집으로**를 누르면 전용 편집 화면으로 이동합니다. 미저장 변경이 있으면 확인하며, 기억과 포트레이트는 별도 자료로 저장합니다.

- 이름·등급(5성/4성)·이미지와 최대 한계돌파 HP/공격력/방어력을 입력합니다. 이름 끝의 +0~+5는 저장할 때 제외합니다.
- 강화 +0~+5 태그를 선택하고 **이 단계에 효과 추가**로 여러 효과를 입력합니다. 조건은 효과별 별도 칸에 한국어·일본어로 기록합니다.
- 확인하지 못한 단계는 비워 둡니다. 효과가 비어 있으면 사이트에 미등록으로 표시합니다.
- 공격력·스피드 등의 효과는 설명에서 자동 인식하고, **효과 분류 태그**에서 추가로 지정할 수 있습니다. 조건 문구와 최대 스테이터스는 효과 검색에 포함하지 않습니다.
- 기억 저장과 같은 방식으로 로컬 백업과 충돌 감지를 수행합니다. 서버 반영은 기억과 포트레이트를 함께 준비·검증합니다.
- 예시 이미지 3장은 인게임 화면 원본입니다. 깨끗한 포트레이트 일러스트를 구하면 **이미지 가져오기**로 교체할 수 있습니다.

포트레이트의 **입수처**는 배포·스토리·푸엘라 픽투러 중 하나를 선택합니다. 기존 자료의 입수처는 임의 지정하지 않고 미등록으로 두며, 수정해 저장할 때 선택합니다. 스토리를 고르면 연결할 스토리 선택란이 나타나지만 현재는 도감 추가 전이라 비활성 상태입니다. 향후 목록에서 선택한 `story_id`를 저장하도록 준비했습니다. 스토리 이외의 입수처로 바꾸면 스토리 참조는 해제됩니다.

## 포트레이트 이미지 초벌 입력

포트레이트 편집 화면의 **이미지로 새 포트레이트 만들기**로 인게임 화면을 선택하거나, 기존 자료의 **인게임 이미지로 초벌 입력**을 누릅니다. 등록된 출처 이미지가 있으면 사용하고 없으면 파일을 선택합니다.

검토 창에 이름(강화 꼬리 제외), 5성/4성, 최대 HP·공격력·방어력, 화면에 표시된 강화 단계와 복수 효과·장착 조건을 표시합니다. **편집기에 적용**은 자동 저장이나 서버 반영을 하지 않습니다. 입수처를 직접 선택하고 판독 결과를 확인한 뒤 저장하세요.

이미지에 없는 다른 강화 단계는 생성하지 않습니다. 기존 자료에 적용할 때는 판독한 단계의 효과만 교체하고 다른 단계·식별자·입수처·스토리 참조·일러스트를 유지합니다. 수치·등급을 판독하지 못하면 새 자료에서는 빈칸으로 두고, 기존 자료의 확인된 값은 유지합니다. 단계가 불명확한 효과는 어느 단계에도 임의 배정하지 않고 검토 메모에 원문과 번역을 보존합니다.

이미지를 OpenAI로 전송하고 기존 ChatGPT 로그인 Codex 사용량을 사용합니다. 진행 중 취소할 수 있으며 완료·실패 후 임시 입력 자료를 정리합니다.


### 수정 요청 관리

기억·포트레이트 상세 화면 맨 아래 **수정 요청**에서 내용을 보내면 서버에 접수됩니다. 요청은 최대 2,000자이며 개인정보를 입력하지 않습니다.

입력툴 상단 **수정 요청 관리**에서 요청 일시(한국 시간), 해당 페이지, 요청사항, 처리 여부를 표로 확인합니다. 미완료·완료·전체 필터와 100건 단위 페이지 이동을 지원합니다. 미완료 요청의 **완료** 버튼은 처리 상태만 변경하며, 실제 도감 수정은 편집·저장·서버 반영을 별도로 진행합니다. 열려 있는 편집 내용은 유지됩니다.

조회와 완료 처리는 기존 Cloudflare 로그인이 필요합니다. 공개 API에서는 요청 내용 조회나 완료 처리를 허용하지 않습니다. 요청 내역은 D1의 `correction_requests` 테이블에 별도 보존되며 도감 자료를 다시 반영해도 유지됩니다. 원본 IP 주소는 요청 테이블에 저장하지 않으며 일별 해시로 일일 접수량을 제한합니다(접속자별 10건, 전체 500건). 최초 설치·업데이트 시 `0011_correction_requests.sql` 마이그레이션을 적용합니다. 입력툴 서버 반영도 테이블과 색인을 자동 준비합니다.
